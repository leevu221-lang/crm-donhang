⚙️ Cài Đặt Kết Nối Google Sheet

Dán đường link Web App Google Apps Script của trang tính vào đây để form trên GitHub lưu dữ liệu trực tiếp vào Google Sheet của bạn.

Cách lấy link Web App (chỉ cần làm 1 lần):
  1. Mở Google Sheet ➔ Tiện ích mở rộng ➔ Apps Script.
  2. Góc trên bên phải, bấm nút xanh Triển khai ➔ Triển khai mới.
  3. Chọn loại: Ứng dụng web. Mục Ai có quyền truy cập chọn: Bất kỳ ai (Anyone).
  4. Bấm Triển khai và sao chép URL ứng dụng web (dạng: https://script.google.com/macros/s/.../exec).
